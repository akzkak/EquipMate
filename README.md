# EquipMate

A simple outfit manager for World of Warcraft Vanilla 1.12.1.
Save your current equipment, switch outfits from the Character panel, and change
outfits automatically.

Works on stock Vanilla 1.12.1.

ClassicAPI (recommended) adds more reliable item tracking, safer equipment changes,
efficient inventory updates, and smart outfit generation.

pfUI integration is used when available.

## Features

- Save, update, and equip outfits from the Character panel
- Choose exactly which equipment slots each outfit controls directly on the Character panel
- Automatic switching for cities, riding, targets, forms, stances, and more
- Ten optional outfit keybindings
- English, German, French, Korean, Russian, Simplified Chinese, and Traditional Chinese
